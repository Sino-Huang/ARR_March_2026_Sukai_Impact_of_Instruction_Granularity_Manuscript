# Video Recording

This folder contains video recordings of VLA (Vision-Language-Action) agents solving various tasks.

## Important Notes

- **Instructions as Captions**: The instructions shown in the videos are provided as text captions rather than being part of the visual input to the VLA agents.

- **Visual Input Augmentation**: The visual inputs fed to the VLA agents were augmented with noise as a form of data augmentation to prevent overfitting and improve model generalization.

## Contents

The videos demonstrate the performance of trained VLA agents on different tasks from the benchmark environments.
